Redoubt

Abstract. Redoubt is a hardware-rooted reference-monitor operating system for AI agents. An autonomous agent can be hijacked — a hidden instruction in a web page is enough — so we assume it has been, and we put the one part that has to stay honest somewhere the hijacked parts can't reach: the most privileged corner of an open RISC-V chip. From there it checks every action the agent tries to take against a set of unforgeable permissions, using plain deterministic logic with no AI in the decision. A fully compromised agent still can't send data it wasn't allowed to send or spend a key it was never given. This manual explains the whole system, one component per chapter, in enough detail to build it and plainly enough to follow without a hardware background.

Each chapter stands on its own and links to the others. If you're new, read them in order — the early chapters set up the ideas the later ones lean on. If you're here for one piece, jump to it.
